# Code of Conduct

## Our Pledge

We are committed to providing a respectful, inclusive, and harassment-free experience for contributors and users of Hope2Live.

## Expected Behavior

- Be considerate and constructive.
- Respect differing viewpoints and experience levels.
- Accept corrective feedback professionally.
- Focus criticism on code and project outcomes.
- Protect private, personal, medical, and location-related information.
- Use the project safely and in accordance with applicable laws.

## Unacceptable Behavior

- Harassment, discrimination, threats, or intimidation
- Personal attacks or insulting comments
- Publishing private information without permission
- Sexualized or predatory content
- Deliberate disruption of discussions or project operations
- Using the project to exploit, mislead, or endanger users

## Enforcement

Project maintainers may edit or remove content and may restrict participation for behavior that violates this Code of Conduct.

## Reporting

Report conduct concerns through a private GitHub issue to the repository owner or through GitHub's reporting tools. Include enough context for the maintainers to investigate while excluding unrelated sensitive information.
